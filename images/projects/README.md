# Featured project images

Featured project cards use the `visualPlaceholder.image` field in
`src/data/projects.ts`.

- Keep `image: null` to show the accessible evidence placeholder.
- Add a public path such as `image: "/images/projects/soc/overview.png"` to
  render a verified image.
- Keep each adjacent `alt` value accurate for the image you add.

Suggested folders:

- `soc/`
- `vulnerability-management/`
- `iam/`
- `network/`
- `home-lab/`
- `ecaa/`
- `experience/`
- `certifications/`

Do not add screenshots containing credentials, private addresses, tokens, or
other sensitive environment details.
